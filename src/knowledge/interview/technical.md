## Explain Machine Learning.

Machine Learning is a branch of Artificial Intelligence that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every scenario.

A typical machine learning workflow includes:
- Data Collection
- Data Preprocessing
- Feature Engineering
- Model Selection
- Model Training
- Model Evaluation
- Deployment

Machine Learning can be broadly categorized into:
- Supervised Learning
- Unsupervised Learning
- Reinforcement Learning

---

## Explain Deep Learning.

Deep Learning is a subset of Machine Learning that uses Artificial Neural Networks with multiple hidden layers to automatically learn complex patterns from data.

Unlike traditional machine learning, deep learning can perform automatic feature extraction, making it highly effective for image processing, speech recognition, and natural language processing.

During my internship at CDAC Kolkata, I worked with deep learning models for image steganalysis, adapting CNN architectures for JPEG color images.

---

## Difference between Machine Learning and Deep Learning.

| Machine Learning | Deep Learning |
|-----------------|---------------|
| Requires manual feature engineering | Learns features automatically |
| Performs well on smaller datasets | Usually requires large datasets |
| Faster to train | Computationally intensive |
| Easier to interpret | More complex |
| Examples: Decision Trees, Random Forest, SVM | CNN, RNN, Transformers |

## Explain CNN.

A Convolutional Neural Network (CNN) is a deep learning architecture primarily used for image processing.

Major layers include:

- Convolution Layer
- Activation Function
- Pooling Layer
- Fully Connected Layer
- Output Layer

CNNs automatically extract spatial features from images.

## What is overfitting?

Overfitting occurs when a model learns the training data too well, including noise, causing poor performance on unseen data.

Ways to reduce overfitting:

- More data
- Cross-validation
- Regularization
- Dropout
- Early stopping
- Data augmentation

Normalization is the process of organizing data to reduce redundancy and improve consistency.

Common normal forms include:

## What is RAG?

Retrieval-Augmented Generation (RAG) combines document retrieval with Large Language Models.

Instead of relying only on model memory, the system retrieves relevant information from a knowledge base before generating a response.

This portfolio chatbot itself is built using a RAG architecture where my personal knowledge base is indexed and retrieved before answering interview questions.

---

## Explain vector embeddings.

Embeddings convert text into numerical vectors that capture semantic meaning.

Similar meanings produce vectors that are close together in vector space, enabling semantic search.

## How do you approach debugging?

When debugging, I generally follow a structured process:

1. Reproduce the issue.
2. Read error messages carefully.
3. Isolate the problem.
4. Test assumptions.
5. Use logging or debugging tools.
6. Verify the fix.
7. Test for regressions.

I prefer understanding the root cause instead of applying temporary fixes.
